GitHub Pages can only serve static files, so the forum itself cannot live inside this domain. Discussions is GitHub’s forum for the project: github.com/mhsgoud/mechanicsreference/discussions.

How to post

01 — Sign in

Create or use a GitHub account. That is what identifies authors and sends replies to your inbox.

02 — Choose a category

Q&A for help, General for theory, Show and tell for work you want to share.

03 — Write the thread

State the continuum or numerical setting, what you tried, and what you expected. Equations in Markdown are fine.
